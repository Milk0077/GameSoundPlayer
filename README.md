# Yiqth 音效器
利用voicemeeter实现在游戏或kook等语音软件播放自定义音乐、音效（需要安装voicemeeter）
## 使用教程
Yiqth 音效器（使用已安装的 Voicemeeter）
1. 打开 Voicemeeter，再双击 Yiqth 音效器.exe。
2. 在程序右侧选择真实麦克风。
3. “混音输出到”选择 Voicemeeter Input (VB-Audio Voicemeeter VAIO)。首次启动通常会自动选择。
4. 在 Voicemeeter 的 Voicemeeter Input 虚拟输入通道打开 B1。
5. 在游戏、Discord、OBS 等软件中，把麦克风选为 Voicemeeter Out B1。
6. 在 Yiqth 音效器添加音效或音乐并播放。
